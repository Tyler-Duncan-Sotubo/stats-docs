# Changelog

## V1 — May 2026

Initial public release of the TooXclusive API.

### Endpoints

- `GET /v1/artists` — browse and search artists
- `GET /v1/artists/:slug` — full artist profile
- `GET /v1/artists/:slug/history` — 90-day stream history
- `GET /v1/songs/:slug` — song detail with charts and features
- `GET /v1/songs/search` — search songs by title
- `GET /v1/milestones/recent` — latest milestone crossings
- `GET /v1/milestones/timeline/:artistSlug` — artist milestone history
- `GET /v1/leaderboard/streams` — top artists by total streams
- `GET /v1/leaderboard/listeners` — top artists by monthly listeners
- `GET /v1/leaderboard/songs` — top songs by streams
- `GET /v1/trending/artists` — trending artists by momentum
- `GET /v1/trending/songs` — trending songs by momentum
- `GET /v1/albums/:slug` — album with tracklist
- `GET /v1/charts/:chartName/:territory` — chart entries

### Data coverage

- 20,000+ artists
- 1.2 million songs
- 90,000+ milestone events
- Charts: Official Afrobeats Chart UK, Spotify Daily NG, Apple Music NG and more
