# TooXclusive API

The official music data API for Afrobeats and African music — built on the infrastructure powering [TooXclusive Stats](https://tooxclusive.com/stats).

## Base URL

```
https://api.tooxclusive.com/api
```

## What's available

- **20,000+ artists** — streams, monthly listeners, chart history, awards, certifications
- **1.2 million songs** — stream counts, daily deltas, release dates, features
- **Milestones** — every time an artist or song crosses a streaming threshold
- **Charts** — Official Afrobeats Chart UK, Spotify Daily NG, Apple Music NG and more
- **Leaderboards** — top artists and songs by streams and listeners
- **Trending** — momentum-scored artists and songs updated daily
